# PitchMe

> PitchMe is a recruitment data intelligence platform that enriches, verifies, and
> deduplicates candidate records so an existing ATS or CRM database becomes an
> activated talent pool. It appends verified contact details, employment history,
> credentials and skills from a stated 30–40+ sources, writes the result back into
> the customer's ATS, and surfaces career-intelligence signals for AI-driven sourcing
> and outreach. Distribution is via marketplace-certified native ATS integrations,
> plus a custom API for any other ATS or recruitment platform.

This file was GENERATED by API Evangelist from the public PitchMe website and this
repository's artifacts. PitchMe does not publish an llms.txt of its own —

## Status of the machine-readable surface

PitchMe advertises API access but publishes no machine-readable contract and no
developer documentation. Verified 2026-08-14:

- No OpenAPI, Swagger, GraphQL or AsyncAPI document at any host we could identify.
- No developer portal. `docs.pitchme.co`, `developers.pitchme.co` and
  `developer.pitchme.co` do not resolve.
- `api.pitchme.co` resolves and fronts a live application (paths under `/api*` are
  answered by an application 404, not the nginx 404 served elsewhere), but every
  anonymous path returns 404 — including `/openapi.json`, `/swagger.json`,
  `/api-docs`, `/docs`, `/redoc` and `/graphql`.
- No `/.well-known/` documents on any host: no `security.txt`, no
  `openid-configuration`, no `oauth-authorization-server`, no agent card.
- No MCP server. PitchMe states on its blog that MCP servers are something it is
  "investing in" — a roadmap item, not a shipped surface.
- No first-party SDK on npm, PyPI or any other public registry.
- No pricing page; pricing and API access are obtained through a demo booking.

Agents cannot call PitchMe today without a commercial relationship.

## Integrations

Marketplace-certified native ATS/CRM integrations, per
https://pitchme.co/integrations: Bullhorn, Greenhouse, JobDiva, LaborEdge Nexus,
Vincere, Avionté, Lever, Salesforce, Jobvite, Ashby. Anything not on that list is
served by "Custom Integration via API", which is arranged through a sales
conversation rather than self-serve credentials.

- [PitchMe on the Bullhorn Marketplace](https://www.bullhorn.com/marketplace/pitchme/)
